# AhaSlides 答案提示

[English](README.md) · 简体中文

适用于 Chrome / Edge 的扩展，根据 AhaSlides 参与者接口返回的答案，在答题网页上高亮正确选项。无需构建、后端或模型 API Key。

## 功能

- 用青绿色边框和 ✓ 标记正确选项，支持多个正确答案。
- 按选项文字、ID 或图片地址匹配，支持选项乱序。
- 简洁的提示条同时列出答案，文字题也会显示可接受的备选答案。
- 随切题自动更新并清除旧标记，支持暂停、继续、刷新和收起提示条。

## 安装

1. 将本仓库下载为 ZIP 并解压，或克隆仓库。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择包含 `manifest.json` 的文件夹。
5. 打开或刷新 `https://audience.ahaslides.com/…` 上的 AhaSlides 参与者页面。

更新文件后，在扩展管理页重新加载扩展，再刷新答题页面。

## 使用

题目出现后，正确选项会自动标注，答案也会显示在右下角提示条中。扩展不会选择选项、填写内容或提交答案。

| 控件 | 作用 |
| --- | --- |
| 暂停 / 继续 | 暂停或恢复查询和高亮。 |
| 刷新 | 立即重新读取当前页面，也可用于演示重新开始后恢复监听。 |
| − / + | 收起或展开提示条，收起后仍继续工作。 |
| 工具栏图标 | 收起或展开提示条。 |

普通响应或请求失败后等待 1.5 秒；排行榜返回后立即发起下一次查询。演示停止时结束查询。

## 支持范围与限制

- 支持 `.com` 参与者页面；短接入链接跳转到参与者页面后即可使用。
- 选择题支持选项高亮，文字题在提示条显示答案。图片选项需能匹配到选项 ID 或图片地址。
- 暂不支持配对、排序题的网页标注，以及 `.eu`、主持人或编辑页面和加密接口响应。
- 答案来自作者配置。接口未提供答案时，扩展不会猜测。
- 浏览器可能限制后台标签页的查询频率。
